# Car Price Prediction Using Machine Learning

## Project Description
This project uses machine learning to predict car prices from car-related data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Dataset
Cars Datasets 2025.csv

## Machine Learning Model
The model is trained using a regression algorithm.

## Evaluation Metrics
- Mean Absolute Error (MAE)
- R² Score

## How to Run
1. Install Python.
2. Install required libraries:
   pip install pandas numpy scikit-learn joblib
3. Keep the CSV file inside the dataset folder.
4. Run main.py.

## Output
The program displays the evaluation results and saves the trained model as car_price_model.pkl.
